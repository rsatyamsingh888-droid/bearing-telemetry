# Data licence

This repository contains code only. No dataset files are stored here.

The project uses the University of Ottawa Rolling-element Dataset - 
Vibration and Acoustic Faults under Constant Load and Speed condtions
(UORED-VAFCLS), version 5:

- Authors: Mert Sehri, Patrick Dumond, University of Ottawa
- Mendeley Data, DOI: 10.17632/y2px5tg92h.5
- Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)

Figures in this repository that show data from this dataset are credited
to the authors and remain under CC BY 4.0. The MIT licence of this
repository covers the code only.

## How to get the data

1. Download the full archive ("Download All") from
   https://data.mendeley.com/datasets/y2px5tg92h
2. Run `python scripts/prepare_data.py <path to the zip or unzipped folder>`

Only the raw CSV files are used.
